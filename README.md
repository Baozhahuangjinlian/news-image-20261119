A one-day newspaper front page summing up the world's news of Thursday 19 November 2026: Trump, Xi and Putin hold their first trilateral summit in Shenzhen; the ICJ rules Myanmar guilty of genocide against the Rohingya; Iran widens the Gulf war; Ukraine hits the Kerch Bridge again; Israel crosses the Gaza ceasefire line; and Anthropic's record $81.3bn IPO. The front page is composed with PIL from a generated lead illustration plus real headlines, set in large type so it stays legible at about 300 pixels across.

## Run it

```sh
python3 main.py
```

`main.py` copies `entry.png` (1024x1024, the front page) to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset). It runs with no network and writes the same bytes on every run.
